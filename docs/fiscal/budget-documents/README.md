- 금액 오른쪽 두 칸(전년도예산액·기정액, 비교증감)을 그 행 금액 칸의 값 순서(행 금액·재원 금액)와 맞춘다. 「금액 − 앞 칸 = 비교증감」이 되는 짝만 쓰며, 붙어 나온 숫자(「△11485,286」 → △11·485,286, 「00」 → 0·0)도 이 식으로만 나눈다. 독립 검산은 「앞 칸 상위 = 하위 합」(상위가 크면 이번 문서에 없는 사업이 들어 있는 경우로 따로 표시, 상위가 작으면 문제).
- 추경 사업명세서는 바뀐 하위 항목만 싣는다. 상위 금액 ≠ 하위 합이어도 상위 비교증감 = 하위 비교증감 합이면 맞는 문서로 본다(partial_listing).
- 병합된 왼쪽 칸에 들어간 이름 조각(「지진」「시군」 등)은 그 세부사업 아래 부기(Ο) 이름이 「조각+세부사업명」으로 시작할 때만 붙인다. 바로 아래 이름에 근거가 없고 뒤쪽 형제 세부사업에 근거가 있으면 그쪽으로 옮긴다(2023 본예산 「지진 옥외대피장소 안내표지판 설치」). 근거가 없으면 이름에 붙이지 않고 「배치 근거 없는 이름 조각」 표시로 남긴다(2023 본예산 2건).
- 추경 산출식 앞 「경정」 표시는 이름이 아니라 표시(annotations)로 남긴다(86행).

## 5. 서버 반입·화면·MCP

- 묶음 형식 welfare-budget-document-v1(factory/budget/build-budget-pack.mjs, 설정 factory/budget/configs/*.json): data/budget/documents.jsonl·revisions.jsonl·lines.jsonl. 편성 단계 ID(brev-)는 문서 ID·단계·추경 차수·원문 해시로, 행 ID(bl-)는 단계 ID·행 번호로 정해 언제 만들어도 같다.
- 서버 검사(lib/imports/budget-pack.ts): 모르는 필드·로컬 경로 거절, 단계(proposal/adopted_initial/adopted_supplementary/settlement/other/unknown)·추경 차수(추경만 필수)·단계 근거 필수, 추경에 「전년도예산액」 칸 금지, 계층(부모가 앞 행·더 높은 계층), 금액 형식, 재정주체 ID가 지방재정365 자료에 있는지. 상위=하위합·재원합·비교증감을 서버가 다시 계산하고 묶음이 「일치」라고 적은 검산이 다르면 거절.
- 저장(마이그레이션 0074): budget_document·budget_revision·budget_line(부기명은 부기 행에만)·budget_funding_component·budget_active_revision. 문서 사실 반입과 같은 /admin/imports에서 검사 → 해시 확인 승인 → 활성화. 같은 문서의 새 원문·새 추출 버전은 이전 단계를 공개 목록에서 빼고(행은 보존) 되돌리기·차단도 같은 버튼으로 된다. 문서 사실 활성화가 공개 중인 예산서 반입을 「새 묶음으로 바뀜」으로 잘못 바꾸던 공통 쿼리도 함께 고침.
- 화면: 복지예산 아래 「예산서(편성 단계 문서)」 구획. 지방재정365 결과표와 분리하고, 문서·단계·근거·범위·검산·원문 링크, 세부사업 찾기, 세부사업을 누르면 편성목·통계목·부기·하위 산출항목·산출식·재원, 앞 칸(전년도/기정액)·비교증감, 같은 재정주체의 지방재정365 예산현액 대조(기준·규칙을 함께 표시)를 보여 준다. 쪽은 「PDF n쪽」(인쇄 쪽 번호와 다를 수 있음).
- 공개 API: /api/budget/documents(?entity·year → 단계 목록, ?revision → 개요·대조, &line → 하위 전체).
- MCP: get_fiscal_catalog catalog_type=budget_document(단계 목록), find_budget_projects 결과에 budget_documents(document_revision_id·budget_line_id·단계·문서 금액), compare_budget_periods comparison_basis=document_stage(양쪽 document_revision_id 필수, observation_date와 섞으면 MIXED_BASIS/DOCUMENT_REVISION_REQUIRED, 회계연도·재정주체·회계 확인, project_selection은 fiscal_project_ids·budget_line_ids·detail_project_query 가운데 하나, 오른쪽이 추경이면 기정예산액 = 왼쪽 금액 여부).
