# 복지통계 검색·조건 복원·비교 CSV

- 통합 목록에서 출처(KOSIS / 지표누리 / 공식 인구통계), 분야, 검색어, 지역 비교 가능 여부를 함께 적용한다. 비교 가능 여부는 확인된 데이터셋의 비교 묶음으로 판정하며 추가 통계값을 초기 응답에 싣지 않는다.
- 검색 조건, 페이지, 상세 계열·기간과 비교 항목·지역·기간을 URL에 기록한다. 상단 지도 조건을 보존한다. 공유·새로고침·뒤로가기는 같은 파서를 사용한다. 통계 변경은 이전 통계의 상세·비교 조건을 해제한다.
- URL의 출처·식별자·기간 형식을 검증하고 비교 지역은 네 개로 제한한다. 지역 파라미터 미지정(기본 전국·제주)과 빈 목록(명시적 미선택)을 구분한다. 존재하지 않는 비교 기간은 현재 수록 범위를 따른다.
- 비교 CSV는 화면과 같은 항목·지역 순서 및 최신 시점부터 내보내며 한 지역·시점당 한 행이다. 수치와 원문값, 단위, 상태, 원문 계열, 출처 URL, 표시 자료 확인시각을 포함한다. 인구 통계는 기준일과 연령 집계 범위도 포함한다.
- 결측·비공개 값은 숫자 열을 비우고 상태를 유지한다. 연도 사이 결측도 행으로 보존한다. CSV는 UTF-8 BOM, CRLF, 따옴표 이스케이프와 수식 문자 보호를 사용한다. 수치·원단위를 변환하거나 지역·월별 값을 합산하지 않는다.
- `lib/statistics-explorer-state.test.mjs`와 `lib/statistics-comparison-csv.test.mjs`에서 필터 조합, URL 왕복·입력 검증, 빈 선택, CSV 범위·수치·상태·출처·서식 보호를 검사한다. 실제 브라우저에서 조건 변경 후 새로고침, 복사 버튼과 다운로드 파일을 확인한다.
