# KOSIS 복지 주제 보강

- 원문 목록: https://kosis.kr/statisticsList/statisticsListIndex.do?parentId=G.1&vwcd=MT_ZTITLE&menuId=M_01_01
- 확인일: 2026-10-16. 목록 31종은 `kosis-welfare-directory-2026-10-16.json`에 보존했다.
- 기존 14종과 새 대표 수치표 16종으로 총 30종의 수치를 연결했다. 고령화연구패널조사는 KOSIS 목록에서 연도별 파일로 제공되므로 원문 안내로 구분했다.
- 새 수치는 브라우저에서 보이는 공식 KOSIS 표의 제목, 원자료 갱신일, 단위, 조회된 머리글·셀을 `kosis/*.json`에 저장했다. `node scripts/statistics/build-kosis-snapshot.mjs`로 확인본을 생성한다. 기본 조회된 기간만 포함하며 전체 원문 수록기간과 구분한다.
- 기존 27개 KOSIS 확인본의 수치·항목·메타데이터는 보존했다. 지표누리의 국민기초생활보장 `2,837천명`과 KOSIS의 `2,836,706명`은 각 원자료의 정밀도·단위를 유지한다.
- 시점이 행에 있는 연금통계는 시점 열을 연도로 읽고 나머지 분류를 계열로 보존했다. 병합 표시 때문에 비워 둔 상위 분류는 바로 위 분류를 이어 읽는다. 전체/소계와 하위 항목을 합산하지 않는다.
- 단위가 여러 개인 장애인생활체육조사는 비율(%)과 5점 만점 평균(점)을 구분한다. 월별 차상위 수급자는 월을 항목명에 보존하고 기본값은 12월로 설정했으며 여러 달을 합산하지 않는다.
- 조사 사례수·추정수는 행정자료의 전체 대상자 수가 아니다. 노인일자리·장애인삶·한부모가족·자립준비청년·노후보장 패널의 모집단·단위 설명을 함께 제공한다. 장기요양 판정 계에는 등급외도 포함된다.
- 수치는 저장된 공식표 확인본이며 KOSIS API 자동 갱신을 새로 구성한 것은 아니다. 출처별 표 링크와 확인시각을 웹·CSV·MCP에 함께 제공한다.
