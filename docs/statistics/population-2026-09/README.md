# 지역별 연령층 주민등록인구 확인본

## 자료 범위

이 확인본은 **2026년 9월 30일 기준 전국과 16개 광역시·도**의 주민등록인구를 담는다. 중장년층은 만 40~64세, 노년층은 만 65세 이상, 아동은 만 0~17세다. `verified.json`과 운영 데이터 `lib/statistics/population-verified.ts`에 같은 수치와 근거를 보존한다. 원문 확인 시각은 `2026-10-10T07:29:02.567133+00:00`(한국시간 2026년 10월 10일 16:29:02)이며, 인구의 기준일과 별개다.

거주자·거주불명자·주민등록 재외국민을 포함하고 외국인은 제외한다. 지역별 비중의 분모는 **같은 지역·같은 기준월의 전체 연령 주민등록인구**다. 전국 행과 16개 시도 행을 한꺼번에 더하면 중복 집계가 되므로, 지역 합계에는 시도 행만 사용한다. 세 연령층은 전체 연령을 모두 포함하지 않는다. 특히 만 18~39세는 이번 세 항목에 포함되지 않는다.

시·군·구별 자료와 다른 기준월의 자료는 이번 확인본에 포함하지 않았다. 제주특별자치도 수치를 서귀포시 수치로 대체하지 않는다. 이 파일은 배포 시점에 검증한 고정 확인본이다. 운영 기본 조회는 별도의 통계 D1 저장소에서 자동 검증된 최신 월을 제공하며, 이 근거 파일을 자동으로 덮어쓰지 않는다.

## 원문과 보존 형식

| 보존 파일 | 행정안전부 공식 원문 | 용도 |
| --- | --- | --- |
| `mois-age-202609.web.txt` | [연령별 인구현황](https://jumin.mois.go.kr/ageStatMonth.do) | 전체인구·10세별 인구·10자리 행정기관코드 |
| `mois-elderly-202609.web.txt` | [지역별 고령 인구현황](https://jumin.mois.go.kr/etcStatOldAge.do) | 65세 이상 인구 |
| `mois-child-202609.web.txt` | [지역별 아동·청소년·청년 인구현황](https://jumin.mois.go.kr/etcStatChYouth.do) | 아동 0~17세 인구 |

**세 `.web.txt` 파일은 웹 조회 도구가 공식 페이지에서 추출한 텍스트다. 원본 HTML 바이트나 CSV 다운로드 파일이 아니다.** 추출 당시 페이지 제목, 출처 URL, 행 번호, 표 내용을 보존했고 파일별 SHA256을 `verified.json`에 기록했다. 자동 파서가 처리한 표현 형식이라는 한계를 유지한다.

모든 페이지의 표 머리글은 `2026년 09월`이다. 연령별 표의 10자리 행정기관코드를 기준으로 다른 두 표의 지역명을 정확히 대응한 뒤, 모든 지역에서 전체·남자·여자 인구가 일치하는지 확인했다. 고령·아동 표 첫 열의 0~16 값은 연령별 표의 10자리 지역 코드로 오인하지 않는다. 전남광주통합특별시의 원문 행정기관코드는 `1200000000`이다.

## 연령 정의와 계산

국가데이터처 [2024년 생애단계별 행정통계 결과](https://www.mods.go.kr/board.es?act=view&bid=11895&list_no=442561&mid=a10301060700&nPage=1&ref_bid=&tag=)의 중장년층 40~64세·노년층 65세 이상 구분을 참고했다. 이 자료의 연간 인구 수치를 복사한 것은 아니다. 실제 수치는 위 행정안전부 월간 주민등록인구 원문에서 가져왔다.

아동 0~17세는 행정안전부 아동 통계 원문이 표시한 값을 사용한다. 원문은 아동복지법상 18세 미만이라는 정의를 명시한다. 주민등록 인구의 연령이 주민등록상 출생월일과 기준 월말에 따른 **만 나이**라는 점은 [KOSIS의 작성기관 확인 답변](https://kosis.kr/civilComplaint/qnaDetail.do?boardIdx=22124)으로 확인했다.

노년층과 아동 수치는 각각 원문의 해당 연령층 값이다. 중장년층은 같은 기준월·지역·성별의 정확한 여집합으로 계산했다.

```text
40~64세 = 전체 인구 − (0~9세 + 10~19세 + 20~29세 + 30~39세) − 65세 이상
```

이 계산은 전체 연령을 빠짐없이 구분한 정수 산술이다. 60~69세 인구를 나누어 추정하거나 평균·보간을 사용하지 않았다. 남녀 수치에도 같은 계산을 적용했다. `sourceAgeUnder40`는 계산에 사용한 0~39세 인구를 보존한다.

## 검증

`node --test lib/population-statistics.test.mjs`로 다음 사항을 재검증한다.

- 원문 추출물3종의 SHA256, 기준월, 실제 연령 구간과 17행의 완전성
- 원문에서 독립적으로 읽은 전체·남녀·연령대 수치와 확인본 일치
- 원문11개 연령 구간 합계=전체, 모든 수치의 남+여=전체
- 중장년층의 정확한 여집합 계산과 유효 범위
- 시도16개 합계=전국, 지역 코드·이름·계층의 일치
- 운영 데이터셋3종의 각17개 지역, 관측월, 인구 분모, 연령 정의, 원문 출처
- 독립 확인본 조회와 `mode=verified`는 원문 요청 없이 보존된 확인본 반환; 운영 `auto`는 최신 D1 검증 자료를 읽음
- 월별 관측값의 연도 필터, 제주 지역 필터, 미수록 시군구·기간 처리

## CSV 조사와 수집 한계

공공데이터포털의 [지역별(행정동) 성별 연령별 주민등록 인구수](https://www.data.go.kr/data/15097972/fileData.do)는 2026년 9월 말 3,619개 읍면동 행과 성별 단일연령 자료의 CSV를 별도로 안내한다. 파일 다운로드는 로그인 없이 무료로 제공하며 이용허락범위 제한 없음으로 표시되어 있었다. 오픈 API 이용은 별도의 활용신청과 인증키가 필요하다.

이번 환경에서는 공식 CSV 직접 요청이 HTTP502로 실패해 이 파일을 확보하지 못했다. 따라서 이번 확인본의 근거는 위 공식 페이지의 검증된 표 내용으로 한정한다. 시군구 자료를 확보했다거나 공식 CSV를 그대로 반입했다고 표현하지 않는다. 외부 인증키는 사용하지 않았다.
