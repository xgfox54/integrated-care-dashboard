## 웹과 MCP

- `/statistics`: 한 목록에서 통계명 검색·분야별 보기 버튼(전체·중장년·노인·아동·장애인·사회보장·보건·의료). 출처가 중복된 4쌍을 묶어 총 70개 통계 항목, 수치 조회 10개, 6개 분야를 표시한다. 원래 출처·작성 정보와 기존 ID 링크는 보존한다. 통계기관 11곳은 별도 원문 서비스 영역에 표시하며 통계 항목 수에 합산하지 않는다. 인구는 지역별 막대·표·CSV, 기존 전국 표는 항목/연도 선택·시계열·표·CSV를 제공한다.
- `/api/statistics`: 기존 출처별 ID를 보존한 목록. `query`, `kind=indicator|approved|portal|population`, `category`, `data_only`, `offset`, `limit` 사용.
- `/api/statistics?id=stat:2760&from_year=2021&to_year=2025&series_id=row-1`: 수치와 출처.
- `/api/statistics?id=population:middle-aged&from_year=2026&series_id=region:5000000000`: 제주 중장년 인구와 해당 월의 분모. 노년은 `population:older`, 아동은 `population:children`. 월자료의 연도 필터도 지원한다.
- `mode=verified`: 배포 시 확인한 고정 자료. 기본 `auto`는 D1에 저장된 최신 검증 자료와 `auto_refresh` 상태를 읽는다. 아직 성공 자료가 없으면 배포 확인본을 표시한다. 웹·API·MCP의 읽기는 같은 저장소를 사용하며 각 조회 자체가 원문 전체를 동기 수집하지 않는다.
- `/api/statistics?view=sources`: 공식 출처 4곳, 기관 목록, 연결 범위.
- `/api/statistics?view=current`: 화면 일괄 갱신용 저장 자료 10종.
- `/api/statistics?view=status`: 마지막 실행·성공·재확인 예정, 범위별 오류와 실제 갱신 정책. 민감한 실행권·PC 인증값·원문 HTML은 공개하지 않는다.
- MCP 도구: `search_statistics`, `get_statistics_data`, `get_statistics_sources`. 기존 `search`/`fetch`와 `get_dataset_status`에도 연결.
- 통계 `revision`은 기존 `release_bundle_id`의 D1 구성요소와 독립된다. 수치를 인용할 때 통계 revision, 기간, 단위, 출처, checked_at을 함께 기록한다.

## 갱신과 실패 처리

### 실행과 저장

신규 `0111_statistics_refresh.sql`은 통계 전용 테이블 두 개만 추가한다. 기존 D1 테이블·수집 설정·LAW_OC 등 Secret과 숨김 메뉴를 변경하지 않는다. `statistics_refresh_scope`는 전국 표 7개와 인구 묶음 1개, 총 8개 범위의 마지막 정상 자료·직전 자료·실행 상태·인구 중간 단계를 저장한다. `statistics_refresh_worker`의 조건부 실행권을 모든 Worker와 PC 깨우기가 공유한다. 기존 자료가 있는 행을 배포 확인본으로 초기화하지 않는다.

정상 확인 후 다음 확인은 24시간 뒤다. 실패 시 1시간부터 지수적으로 늘려 최대24시간 뒤 다시 확인하며, 원문 `Retry-After`가 더 길면 그 시각을 존중한다. 실패나 실행 중단이 성공 시각·수치를 바꾸지 않는다. 같은 기간의 공식 정정은 반영하지만 현재 D1와 배포 확인본 중 더 최신인 기준기간보다 과거로 돌아가는 응답은 거절한다. 연간 표의 기존 기간도 유지한다.

현재 Sites 호스팅에서 cron이 실행된다고 가정하지 않는다. 일반 웹 요청의 성공 응답과 인증된 기존 PC의 `POST /api/press/tick`, `GET·POST /api/press/relay` 성공 응답 후 별도 `waitUntil`이 확인을 진행한다. `/mcp`, 상태 전용 PC 조회, 인증 실패·잘못된 메서드는 확인을 시작하지 않는다. PC 응답과 기존 보도자료 적체 수는 변경하지 않는다. 기존 GPT 깨우기 자동화의 일시정지 상태도 보존한다. PC가 모두 꺼져 있고 웹 요청도 없으면 다음 접속 때 이어간다.

### 원문 검증

등록된 10개 고정 공식 URL과 두 호스트의 robots.txt만 요청한다. 임의 URL·키·SQL은 받지 않는다. robots가 금지되거나 읽히지 않으면 해당 원문을 요청하지 않는다. 정책은 D1에서 최대24시간, 오류는1시간 재사용한다. 호스트별 요청 간격은3초이며 글로벌 실행권과 D1 기록으로 여러 Worker의 요청도 직렬화한다. 본문 포함5초 제한, 통계표1MiB·robots64KiB 상한, 호출당 최대22초·16단계 기본 예산을 적용한다. 리다이렉트는 따라가지 않는다. 완료·실패·중간 저장에도 현재 실행권을 확인한다.

전국 표는 제목·단위·기간·항목 이름·행 개수를 검증한다. 인구는 계·남·여,11개 연령구간,17개 지역 집합, 전국과 시도 합, 세 원문의 동일 월·분모·연령 포함 관계를 확인한다. 원문3개가 모두 통과한 뒤 JSON 공개본1개를 바꾸므로 일부 연령층만 다른 달로 공개하지 않는다. 인구 중간 단계는 raw HTML 대신 검증한 행·헤더 근거·해시를 보관하며 최대24시간 동안 다음 PC 호출에서 재개할 수 있다.

화면은 관측연도·월과 자동 확인 시각을 구분한다. 보이는 동안 최초15초 후, 이후 요청 완료60초 간격으로 저장된 결과를 읽어 카드·상세정보를 함께 반영한다. 숨겨진 탭에서는 중지하고 다시 보이면 확인한다. 오류·결측을0으로 표시하지 않으며 늦은 이전 응답이 최신 수치나 상태를 덮지 않는다.

원문 조회 허용 여부와 실제 연결·HTML 구조 지원은 운영 상태로 확인해야 한다. 웹 검색에서 원문 표를 확인했다는 사실만으로 Worker 직접 수집 성공을 주장하지 않는다. 자동 수집 실패 시 마지막 확인본과 재확인 상태를 제공한다.
