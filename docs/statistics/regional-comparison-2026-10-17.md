# 복지통계 지역·연도 비교

통계 상세의 `지역·연도 비교`는 현재 API 발행본과 같은 `StatisticsResult`를 사용한다. 별도 수치를 저장하거나 DB를 변경하지 않으며, 자동 갱신 결과가 기존 상세에 반영될 때 비교에도 반영된다.

## 지원 범위

| 통계 | 비교 항목 | 지역 |
| --- | --- | --- |
| 국민기초생활보장수급자현황 | 계, 일반수급자, 시설수급자 각각 | 전국 + 17개 시도 |
| 장애인 건강보건통계 | 계 / 수검률 | 전체 집계 + 거주지역별 17개 시도 |
| 차상위 및 한부모가족 수급자 현황 | 1~12월 각각 | 계 + 시도별 17개 시도 |
| 장애인 생활체육조사 | 주관적 건강상태 응답 5종, 5점 만점 평균 각각 | 전체 집계 + 원표에 수록된 거주지역 |
| 주민등록 인구 4종 | 각 통계의 동일 연령 범위 | 전국 + 원자료 광역시도 |

전국·제주를 기본 선택하고 4개 지역까지 추가·해제할 수 있다. 비교 항목을 바꾸면 같은 지역명을 유지하며 기간은 초기화한다. 인구는 현재 한 기준월만 수록되어 시점 비교로 표시하며 과거 연도를 생성하지 않는다.

## 비교 기준

- KOSIS는 확인된 표별 라벨 구조를 명시적으로 대응한다. 출처 URL·단위·측정 항목이 모두 같아야 한 비교 집합에 들어간다. 이름이 유사한 다른 통계나 성별·연령별 항목은 섞지 않는다.
- 원문 `전체`·`계`를 전국으로 표시하는 표는 원문 항목 펼침에서 실제 라벨을 확인할 수 있다. 전국은 지역 합산으로 만들지 않는다.
- 차상위의 각 월은 별개 항목이다. 12개월을 합산하지 않는다. 장애인 생활체육 응답 비율(%)과 평균(점)도 분리한다.
- 결측·비공개는 표에 상태를 적고 선을 끊는다. 잠정·추정 상태와 원단위는 유지한다. 비어 있는 연도도 차트에서 연결하지 않는다.
- KOSIS의 과거 지역 명칭과 현재 주민등록 통계의 지역 구분을 서로 변환하거나 합치지 않는다. 비교 가능한 지역이 없으면 수록 범위를 안내하고 기존 연도별 조회를 제공한다.

## 확인

`lib/statistics-comparison.test.mjs`에서 표·단위 분리, 전국·제주 기본 선택, 월별 구분, 상태 유지, 기간 역전, 누락 연도, 인구 범위를 검증한다. 브라우저에서는 지역 추가·해제 및 네 지역 제한, 항목 변경, 기간 변경·역전, 초기화, 단일 기준월, 지역 자료 미제공 안내를 확인한다.
