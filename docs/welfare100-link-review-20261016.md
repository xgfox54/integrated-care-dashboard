# 복지제도100 데이터 연결 재점검 결과

2026-10-16. 제공된 검토표(v454)와 운영 v458의 현재 자료를 대조했습니다. 건수는 사업 수가 아니라 인용·연결 위치 수입니다.

- 확정 오류 105건 중 103건: 조문·절차·법령 종류·URL 경로 정정 또는 잘못된 연결 차단.
- 확정 오류 중 2건: 원자료의 실제 의도를 확정할 수 없어 원문 표기를 보존하고 확정 링크를 보류했습니다.
- 추가 법령 후보 5건: 주거급여 지급 절차, 차상위계층 정의, 첫만남이용권의 현행 근거를 정정했습니다.
- 매뉴얼 후보 672건: 목록 628, 일반기준 27, 제외목록 14, 표지·목차 3에 직접 설명으로 승격되지 않는 제한 판정을 적용했습니다.
- 오류 아님 68건: 일괄 삭제·변경하지 않았습니다.

## 주요 수정

주거급여 시행령의 잘못된 제4·8조를 제거하고 주거급여법 제7·8조로 정리했습니다. 해산·장제급여 신청은 시행령이 아닌 시행규칙 제17·18조로 수정했습니다. 에너지바우처 사용은 에너지법 제16조의4, 장애인활동지원 수급자격 심의는 제9조, 장기요양비용 심사·지급은 제38조를 연결합니다. 사회보장급여법 제42조 제목은 ‘사회보장사무 전달기구’로 정정했습니다. 첫만남이용권은 2026-09-10 시행 아동수당법 제10조의2로 연결합니다.

매뉴얼의 타사업·타지역 오연결 15건을 제외했습니다. 장애인기업 창업보육실은 올바른 절로 옮겼으며, 원본 240쪽의 해당 사업 설명부터 발췌하고 다음 사업 앞에서 끝냅니다. 타지역 동일 사업명 검수 판정은 제목 일치보다 먼저 적용합니다.

- 광주·전남 조례 70건: 행정구역 개편만으로 폐지·승계를 단정하지 않았습니다.
