# 보도자료 제목 분류 정확도 측정 (2026-10-04)

작업지시서 v5 §18.7의 "확정 복지 자동게시 precision 95% 이상·recall 90% 이상" 초기 목표에 대한 실측 기록이다.

## 표본과 판정

- 표본: 운영 DB `press_item` 전체 117건(2026-10-04 조회, 9개 Source: 보건복지부 RSS 30건, 광역 8곳 87건). 무작위 추출이 아니라 그 시점까지 수집된 전수다. 목표 200건에 못 미친다.
- 판정: 작업자 1인이 제목만 보고 WELFARE/NOT_WELFARE를 붙였다. 이중 판정·합의 절차는 없다. 본문은 열람·저장하지 않았다.
- 기준: 제목의 주된 내용이 복지·돌봄·보건의료 정책 또는 취약계층 지원이면 WELFARE, 지역 행사·산업·일반 안전·문화·행정 일정이면 NOT_WELFARE. 애매한 7건은 판정표의 `borderline`에 이유를 적었다.
- 판정표: `labels-2026-10-04.json` / 측정: `node scripts/press/measure-classification.mjs docs/press/eval/labels-2026-10-04.json <결과파일>`

변경 내용: 미탐이던 `청년내일저축계좌`·`전세피해`·`가짜진료` 유형을 잡도록 `내일저축·희망저축·자산형성`, `전세피해·전세사기`, `가짜진료·비정상진료·부당청구`를 넣었다. 또 `청소년` 한 단어로만 분야가 잡히는 제목(예: 청소년교향악단 단원 선발)은 확정하지 않고 검토로 보류한다. 작업지시서가 정한 대로 신뢰도 숫자를 임의로 조정하지 않고 보류 규칙을 바꿨다.

## 한계

- 변경 후 수치는 같은 표본으로 사전을 고친 뒤 잰 값이라 실제보다 좋게 나올 수 있다(표본 내 측정). 이후 새로 수집된 제목으로 다시 재야 일반 성능을 말할 수 있다.
- 남은 오탐: "의료 AI 실증 생태계"(보건산업 성격, `의료`로 잡힘). 남은 미탐: 농어촌 기본소득, 미래 건강전략 포럼, 국립의학전문대학원 설립. `의료` 한 단어를 보류로 돌리면 응급의료·보건의료인력 같은 정답 3건이 함께 빠져 바꾸지 않았다.
- 제목만 읽는 1단계 규칙 분류다. 모델·검토자 확인(2단계)은 없다.
- 이미 저장된 항목은 저장 당시 사전 버전(`dictionary_version`)의 판정을 그대로 유지한다. 새 사전은 새로 수집되거나 제목이 바뀐 항목부터 적용된다.
