# MCP 1.14.1 호출 최적화

- 노출 도구 16개, 실행 도구 32개 유지. 법령·돌봄자원 비제공 유지.
- 자동 상세의 본문과 함께 출처·기준일·자료 한계·주의사항 보존.
- 실패·시간 초과를 부분 결과에 반영. 상세 근거가 불완전하면 최상위 자료 범위도 불완전으로 표시.
- 조회를 완료한 도구·인수는 후속 추천에서 제외. 동일 상세가 포함된 검색 후보는 식별·출처·경고를 남기고 중복 내용 축약.
- 도구명 일치 시 해당 도구만 탐색. 일반 탐색은 최대 4개 도구와 실제 입력 명세 제공. 중복 분류 및 설명 본문 제거.
- 예산 필수 조회를 검색과 병행. 예산 질문에서는 지역 사업 목록 조회 생략. 오류 복구 인수의 지역·검색어·연도 보존.
- 재정 목록 조회에서 범위별 건수 집계 재사용. 동일 조건의 전체 건수 재집계 제외, 실제 조회 대상 범위로 상세 쿼리 축소.
